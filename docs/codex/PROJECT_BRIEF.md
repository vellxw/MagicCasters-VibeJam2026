# Project Brief — AI-Built 1v1 Magic Duel

## Goal

Create a new browser-based 1v1 magic duel game for VibeJam 2026.

The game should be fast to load, free to play, accessible without login, and multiplayer using Colyseus.

## Core Fantasy

Two mages enter a small arena and fight using magic spells. Some spells can be triggered by voice commands.

The game should feel like a polished jam entry, not a huge unfinished MMO.

## How To Use The Old Prototype

The old prototype must be treated as READ-ONLY.

Use it to understand:

- intended controls
- movement feel
- voice casting behavior
- spell ideas
- visual direction
- current assets if lightweight and useful

Do NOT blindly copy the old game as the final submission.

Because of VibeJam rules:

- the new project should be newly generated in this repo
- most final code should be AI-written
- any copied code must be minimal, documented, and not risk the 90% AI-written requirement

## Final Game Scope

Make a compact 1v1 online duel, not a 12-player arena, not a planet, not a big open world.

Target:

- 1v1 online duel
- quick start
- tiny or medium arena
- no login
- optional username only
- voice spell commands
- keyboard fallback
- server-validated spells
- clean debug overlay
- lightweight visuals

## Do Not Implement Yet

Do not implement:

- SuperSplat / Gaussian Splat
- 12-player mode
- planet arena
- account system
- login/signup
- large asset pipeline
- heavy models
- loading screen
- battle royale
